# JCL Store

A responsive shopping cart application built with React and TypeScript.

## Features

- Browse products fetched from a public API
- Adjust product quantities before adding them to the cart
- Add, update, and remove cart items
- View live cart totals and item counts
- Navigate between Home, Shop, and Cart pages
- Responsive layout for desktop and mobile
- Component interaction tests with Vitest and React Testing Library

## Built With

- React
- TypeScript
- React Router
- Vite
- Vitest
- React Testing Library
- CSS
- Fake Store API

